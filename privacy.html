隐私政策

武理资源共享平台（resource.haoli.site，以下简称“本站”）由站长毫厘个人非商业运营，平台源代码由开发者 zygame1314 独立开发、著作权归其所有（AGPL-3.0 开源）。我们只想安心分享学习资料，不想也不需要拿你的个人信息做别的事。本政策用大白话说明：我们收集什么、为什么收集、保存多久、会给谁看，以及你能怎么管。

一、我们收集哪些信息

1. 你主动提供的信息

  • 账号信息：@whut.edu.cn 学校邮箱（含前缀）、昵称、密码，以及你可选填的学号/卡号。
  • 密码：只保存加盐的 PBKDF2-SHA256 哈希（10 万次迭代），不保存明文，管理员也无法查看你的原始密码。
  • 邮箱验证记录：你从学校邮箱发送到 email-bot@haoli.site 的验证邮件，包含发件地址与主题中的验证码；验证记录 30 分钟内有效，过期记录会被清理。
  • 上传与分享内容：文件本体、文件名、大小、类型、所在目录、描述、外链地址、上传时间与上传者账号。文件存放于 Cloudflare R2 对象存储。
  • 互动内容：留言与回复、点赞、资源表态（如催更、感谢）、资源请愿、通知已读状态。

2. 使用过程中自动产生的信息

  • 下载与预览记录：账号、文件标识、时间、文件大小、IP 地址。用于每日下载额度、反爬与下载量统计，30 天后自动清理。
  • 登录与安全记录：IP 地址、登录失败次数（15 分钟窗口）、人机验证（PoW/验证码）结果、OAuth 授权流水（含 IP 与浏览器 User-Agent，保留 90 天）、管理员操作日志（操作人、对象与原因，保留 3 天）。
  • 通行密钥（Passkey）：公钥、凭据 ID、设备名称、创建与使用时间。本站不会接触指纹、面容等生物特征原始数据，这些数据始终留在你的设备上。
  • 服务器与平台日志：作为基础设施提供商的 Cloudflare 可能记录访问 IP、时间、User-Agent 与错误信息，用于安全防护与故障排查。

3. 我们不会收集的信息

  • 手机号、身份证号、精确位置、通讯录、相册、麦克风与摄像头（全站已通过 Permissions-Policy 禁用后两者）。
  • 除“智慧理工大”登录时你主动提交、且仅用于当次转发给学校认证系统的短信验证码外，我们不收集任何短信内容。
  • 我们不接入广告联盟、不做跨站行为追踪、不购买或出售个人信息。

二、信息的使用目的

  • 验证武理在校身份，创建与保护你的账号；
  • 提供上传、下载、在线预览、搜索、留言、订阅通知等核心功能；
  • 计算每日下载额度，识别并拦截爬虫、批量盗链、恶意刷量与滥用行为；
  • AI 智能搜索（解析搜索意图、生成向量、结果重排）与留言自动审核；
  • 生成匿名聚合统计（如文件总数、下载总量、在线人数），不会用于对你个人的画像或精准推荐；
  • 排查故障、保障服务稳定，以及履行法律法规要求的义务。

三、第三方服务与数据共享

本站不运营自己的服务器，所有功能依赖下列第三方服务。我们只按“实现功能的最小必要范围”向其提供数据：

  • Cloudflare（Pages / Workers / D1 / R2 / Queues / Vectorize / Durable Objects / Email Routing）：站点托管、数据库、文件存储、队列、向量检索与验证邮件路由，处理本站全部业务数据与访问日志。
  • SiliconFlow（api.siliconflow.cn）：AI 搜索的关键词解析、文本向量化与结果重排，以及留言/链接内容的违规审核。向其发送的仅为你的搜索词、留言文本、文件名与描述，不包含密码、邮箱验证码。
  • Google Safe Browsing：对你提交或点击的外链进行恶意网址检测，仅发送待检测的 URL。
  • 学校统一身份认证系统（智慧理工大）：SSO 登录时，学号与密码仅用于向学校系统转发验证，本站不保存该密码。
  • 站长邮箱 / GitHub Issues：当你主动联系我们时，我们会收到你自行提供的内容。

上述服务商可能位于中华人民共和国境外，使用本站即表示你知悉并同意为实现上述功能所必需的跨境传输。 除法律法规要求或你另行授权外，我们不会向任何第三方出售、出租或交换你的个人信息。

四、保存期限

  • 账号信息：账号存续期间保存，注销后按第六节处理；
  • 待验证的注册 / 改密 / 改邮箱记录：30 分钟，过期记录会被清理；
  • 登录失败计数：15 分钟；
  • 下载与预览记录：30 天；
  • 管理员操作日志：3 天；
  • OAuth 授权流水：90 天；
  • 站内通知：60 天；
  • 上传的文件与留言：直至你或管理员删除、或账号注销；
  • Cloudflare 平台侧日志：由 Cloudflare 按其自身策略保留，本站无法单独控制。

五、我们如何保护信息

  • 全站强制 HTTPS 并启用 HSTS，配置内容安全策略（CSP）与防嵌入限制；
  • 密码采用加盐 PBKDF2-SHA256 哈希存储；登录状态使用 7 天有效的 JWT 令牌；
  • 提供通行密钥（Passkey）登录，减少密码泄露风险；
  • 接口限流、人机验证（PoW / 验证码）、下载额度与封禁机制；
  • 管理员权限最小化，关键操作留痕审计。

但请理解：没有绝对安全的系统。请使用独立且足够复杂的密码，不要与其他网站复用。

六、你的权利

  • 查询与更正：登录后可在个人设置中修改昵称、邮箱、密码，管理或删除通行密钥。
  • 删除与注销：可通过下方联系方式申请注销账号。注销后，你的账号、留言、点赞、下载记录等将被删除；已上传的文件会保留以供他人学习，但上传者关联信息将被置空。
  • 撤回同意：你可以停止使用本站并申请注销；清除浏览器本地存储即可移除登录令牌与偏好设置。
  • 拒绝特定处理：不使用 AI 搜索、不发布留言、不上传文件，即可避免相应的数据处理。
  • 响应时限：我们会在收到请求后 15 个工作日内答复；如对处理结果不满，可向网信、市场监管等主管部门投诉。

七、Cookie 与本地存储

本站不设置广告或跨站追踪 Cookie，仅在浏览器本地保存必要的状态信息。站点可能启用 Cloudflare Web Analytics 做匿名访问统计，它不写入 Cookie、不跨站追踪、不识别个人身份：

  • authToken：登录令牌，有效期 7 天，用于识别登录状态；
  • theme、autoTheme：主题偏好；
  • hasSeenTutorial：是否已看过新手教程；
  • hideDownloadLog：是否隐藏下载动态浮层；
  • donationFirstVisit、donationVisitCount、donationHideUntil：打赏弹窗的展示频率控制；
  • browser_guide_dismissed：浏览器使用提示的关闭状态；
  • fac_*（sessionStorage）：当前标签页的接口缓存，关闭标签页即失效。

你可以在浏览器设置中随时清除这些数据；清除后登录状态与偏好会丢失，但不影响浏览公开内容。

八、未成年人保护

本站面向高校师生，不以未满 14 周岁的儿童为服务对象。若你未满 18 周岁，请在监护人指导下使用本站，并在上传、留言前征得监护人同意。若我们发现误收集了儿童个人信息，会尽快删除。

九、政策更新

功能或法规变化时，我们可能更新本政策，并在本页顶部修改“最后更新”日期；涉及重大权利变化的，会在首页公告中提示。继续使用本站即视为接受更新后的政策。

十、联系我们

与个人信息相关的查询、更正、删除、注销或投诉，可通过以下方式联系。本站由站长毫厘运营并作为个人信息处理者，开发者 zygame1314 仅负责源代码维护，不接触你的个人数据：

  • 站长邮箱：Proudly_embers@qq.com
  • 项目仓库：GitHub Issues（仅处理技术问题）
  • 站内反馈：留言板（仅处理一般问题，账号注销请走邮箱）
